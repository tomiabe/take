# Take

A small browser tool for recording concise project preview loops.

## Use it

1. Open Take in one browser tab and the project in another.
2. Add a project name and choose desktop or mobile.
3. Select **Record a take** and choose the project tab in the browser capture prompt.
4. Interact with the product, then return to Take and stop the recording.
5. Set the start and end point, then export the trimmed loop.

## Privacy

Take has no account, backend, uploads, or saved project files. A recording exists only in browser memory until you export it. Settings reset when the page closes.

## Browser support

Use a current Chrome or Edge browser. The browser capture API produces WebM video, which works well for web portfolios. MP4 conversion can be added later if it becomes necessary.
